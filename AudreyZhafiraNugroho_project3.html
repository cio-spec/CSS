Program Description

The ICT Program is designed to help students develop digital skills, problem-solving abilities, and creativity in technology-based learning. Students will learn web development, programming, database management, and Internet of Things projects through practical activities.

Learning Roadmap

Level X

HTML, CSS, JavaScript, PHP, and MySQL

Level XI

Internet of Things, MQTT, sensors, and web dashboards.

Level XII

Python programming fundamentals and final projects.
